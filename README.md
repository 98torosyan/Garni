# Ազատ է · Գառնի

Ազատ հյուրատների որոնում Գառնիում․ հաճախորդը լրացնում է մեկ հայտ, տնատերերը պատասխանում են Telegram-ով։

## Տեղադրում
1. Ստեղծիր ռեպո `azate`, վերբեռնիր այս թղթապանակի ամբողջ պարունակությունը։
2. Settings → Pages → Branch: `main`, folder: `/ (root)` → Save։
3. Կայքը կբացվի `https://98torosyan.github.io/azate/` հասցեով։

## Telegram
1. BotFather-ով ստեղծիր նոր բոտ, պահիր token-ը։
2. Երկու տնատերերն էլ բոտին գրում են `/start`։
3. Հեռախոսով բացիր `.../azate/#setup`, մուտքագրիր token-ը, սեղմիր «Գտնել ID-ները», ընտրիր ամեն տան համար։
4. «Ստուգել կապը»․ եթե հաղորդագրությունը հասավ, ամեն ինչ պատրաստ է։

Token-ը պահվում է միայն քո հեռախոսում և երբեք չի հայտնվում GitHub-ում։


## Տվյալներ
Տների անունները, գները, հատկությունները և նկարները՝ `houses.js`։
